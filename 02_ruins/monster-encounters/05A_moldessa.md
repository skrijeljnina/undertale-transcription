# Moldessa

A **Common Enemy** randomly encountered in **Ruins (Hard Mode)**. A more advanced version of **Moldsmal**.

## Encounter

### With Migospel

```
* Migospel flutters in, carrying
  Moldessa.
```

### x2

```
* You tripped over some
  Moldessas.
```

### x3

```
* A line of Moldessas block the
  path.
```

### Unused

#### With Whimsalot and Parsnik

```
* Party from Hell.
```

#### With Astigmatism and Migospel

```
* Looks like a real party.
```

## ACT

```
* Moldessa
```

```
* Check     * Switch
* Fix       * Lie Down
```

### Select `Check`

```
* MOLDESSA 7 ATK -4 DEF
* Can't decide on a face.
* Can't see friend from foe.
```

### Select `Switch`

```
* You encourage Moldessa to try
  a new look.
* Its face shifts...
```

### Select `Fix`

```
* You adjust Moldessa's face.
* It seems to be happy with its
  new look.
```

### Select `Lie Down`

```
* You lie down and rest.
* Moldessa tucks you in with
  a blanket of moss.

* While you were sleeping, the
  other monsters get bored.
```
