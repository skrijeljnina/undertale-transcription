# Room 9A: Monster Candy

**North** of **Room 9: Leaf Pile**.

## Inspect Candy Pile

`Narrator`

- **Initial Action**

  ```
  * It says 'take one.'
  * Take a piece of candy?
  ```

- **Repeat the Action**

  ```
  *'Take one.'
  * Take a candy?
  ```

Options:

```
Yes

No
```

```
  scum of the earth...
```

```
* You took too much too fast.
* The candy spills onto
  the floor.
```
